## Task 3: Vite installieren

**Warum:** Vite ist ein modernes Build-Tool und Dev-Server für Web-Apps. Zwei Kern-Funktionen:
- **`npm run dev`** — startet einen Dev-Server mit Hot Reload. Änderungen im Code sind ohne Neuladen sofort im Browser sichtbar.
- **`npm run build`** — produziert optimierte statische Files fürs Deployment (in unserem Fall: für die Capacitor-APK).

Ersetzt beim späteren Build-Prozess "HTML-Datei manuell schreiben" durch "Files aus src/ zusammenbauen".

**Files:**
- Modify: `package.json` (dev-Dependency, Scripts)
- Modify: `package-lock.json` (automatisch)

- [ ] **Step 1: Vite als Dev-Dependency installieren**

```bash
npm install --save-dev vite
```

Expected: `added N packages`, `vite` erscheint in `package.json` unter `devDependencies` (Version 5.x oder höher).

- [ ] **Step 2: Scripts in `package.json` ergänzen**

```json
"scripts": {
  "dev": "vite",
  "build": "vite build",
  "preview": "vite preview"
}
```

```js
// Rendert eine einzelne Day-Card als <article>-Element
// Erwartet: { day: string, dish: { name, cuisine, cooktime, imageSrc } }
export function createDayCard({ day, dish }) {
  const article = document.createElement('article');
  article.className = 'day-card';
  article.innerHTML = `
    <img class="day-card__image" src="${dish.imageSrc}" alt="${dish.name}" loading="lazy" />
    <div class="day-card__body">
      <div class="day-card__day">${day}</div>
      <h2 class="day-card__title">${dish.name}</h2>
      <div class="day-card__meta">~${dish.cooktime} Min. · ${dish.cuisine}</div>
    </div>
  `;
  return article;
}
```

- [ ] **Step 3: `src/dashboard/render.js` erstellen**

```js
import { createDayCard } from './card.js';

// Provisorisches Beispiel-Data — echte DATA-Anbindung kommt in Session 2
const SAMPLE_DAY = {
  day: 'Montag',
  dish: {
    name: 'Wildlachs-Bowl',
    cuisine: 'Asiatisch-Fusion',
    cooktime: 35,
    imageSrc: '/dishes/dish-1.jpg',
  },
};

export function renderDashboard(root) {
  root.innerHTML = '';
  const card = createDayCard(SAMPLE_DAY);
  root.appendChild(card);
}
```

- [ ] **Step 4: `src/main.js` erstellen**
